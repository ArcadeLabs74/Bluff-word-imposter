## What is Guess The Imposter?

**Guess The Imposter** is a party game where one player in the group is secretly the imposter.

- **The Crew** sees the secret word (e.g. `SUPERNOVA`).
- **The Imposter** does not know the word—they only see a vague hint (e.g. *"A dying star explosion"*) generated by Google Gemini so they have something to bluff with.
- Players take turns saying a single clue about the word. If your clue is too obvious, the imposter figures out the word. If it's too vague, the group thinks you are the imposter.
- After 1 or 2 clue rounds, everyone votes on who the imposter is.

## Features

- **Pass & Play (1 Phone):** Play together with friends anywhere. One phone is passed around with a 3D hold-to-reveal card so players only see their own role. No accounts or setup needed.
- **Online Multiplayer:** Create a room and share the 6-character code (e.g. `GTI-4892`) or invite link. Everyone plays on their own phone with real-time clue feeds and voting.
- **Dynamic AI Words & Hints:** Uses Google Gemini 2.5 Flash through a Supabase backend to generate fresh secret words and clues. The API key stays on the server so nobody can inspect network traffic to cheat.
- **Offline Preset Decks:** Includes 10+ built-in decks (Food, Movies, Places, Animals, Gaming, Sports, Everyday, Professions, Superheroes, Sci-Fi) so the game always works offline.
- **Mobile-First Bento Design:** Clean industrial layout with sound effects, optimized for small phone screens and desktop browsers alike.

## How to Play

| Phase | What Happens | Tips |
| :--- | :--- | :--- |
| **1. Role Reveal** | Each player checks their role privately. Crew sees the secret word; the imposter sees only the category and a hint. | **Imposter:** Keep a poker face! Read your hint and act natural. |
| **2. Clues** | Go in order around the circle. Each player says one short clue related to the word. | **Crew:** Give clues that only people who know the word will understand. |
| **3. Discussion** | Talk through suspicious clues, hesitations, or weird answers. | **Imposter:** Pay attention to early clues to narrow down what the word is. |
| **4. Vote** | Everyone picks who they think the imposter is. | If the imposter gets the most votes, the **Crew Wins**. If votes tie or an innocent is voted out, the **Imposter Wins**! |

## Getting Started

### Requirements
- Node.js (v20 or higher)
- npm

### 1. Install dependencies
```bash
git clone https://github.com/ArcadeLabs74/Guess-The-Imposter.git
cd Guess-The-Imposter
npm install
```

### 2. Environment Setup (Optional for Online & AI)
Create a `.env` file in the root folder:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> **Note:** The game works out of the box in **Local Pass & Play** mode using preset words even without Supabase credentials.

### 3. Start the dev server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

## Supabase Edge Function (Optional)

If you want live Gemini AI generation in your own Supabase project:

```bash
# 1. Set the Gemini API key in Supabase secrets
supabase secrets set GEMINI_API_KEY="your-gemini-key"

# 2. Deploy the word generator function
supabase functions deploy generate-word
```
